# Čtečka

Jednoduchá čtečka knih nahlas pro Android.

- otevře **PDF, EPUB a TXT**
- čte na pozadí i při **zhasnutém displeji**
- ovládání z notifikace, zamčené obrazovky a sluchátek
- pamatuje si, kde jsi skončil (u každé knihy zvlášť)
- rychlost čtení 0,5–3×, dlouhý stisk ⏮/⏭ skočí o 20 vět

**Instalace:** Releases → nejnovější verze → `ctecka.apk`.

Hlas: český hlas telefonu (Nastavení → Převod textu na řeč). Naskenované PDF (obrázky stránek) přečíst neumí.
